用途与限制

CPython 3.12 对应组合。

本目录是按用途准备的通用 CPU 环境，不是全部历史研究项目的精确复现。 不要与 windows_python_offline_resources/ 或其他 Linux 组混装。

默认集合 不适用于：ARM64、Alpine/musl、非 glibc 系统、GPU/CUDA。 Ubuntu 22.04 需要 glibc ≥ 2.35 且不高于本环境实际 wheel 需求；若最低 glibc 标记 ≤ 2.35，则 22.04 与 24.04 都可作为候选。若某 wheel 需要更新的 glibc，22.04 不可用。

本组能做什么

用 ONNX Runtime CPU 做推理骨架，并用 FastAPI/Gradio/Streamlit 做本地界面。onnxruntime-gpu 不在本环境。

目标解释器：CPython 3.12（Linux x86-64 glibc）。本轮未在目标机安装或运行，不能写成开箱即用。

详细对照见 ../../guides/常用工具与包用途索引_cn.md；安装步骤见 ../../guides/离线安装与使用_cn.md；最小示例见 ../../guides/常见任务快速入门_cn.md。

离线安装

  1. 准备 CPython 3.12 x86-64 运行时（推荐解压 runtimes/python_build_standalone/ 中对应 install_only 包，或自行从官方源码构建）。
  2. 该运行时是 Astral/indygreg python-build-standalone 第三方构建，不是 python.org 官方 Linux 二进制。
  3. 指定解释器并安装：
export PYTHON_BIN=/path/to/python3.12
bash ./install_offline_en.sh
"$PYTHON_BIN"/../bin/python -m pip  # 不使用
./venv/bin/python ./check_environment_en.py

安装脚本使用 venv + pip install --no-index --find-links wheelhouse。 失败即停止，不会静默联网，不会修改系统 Python，不会调用 sudo。
