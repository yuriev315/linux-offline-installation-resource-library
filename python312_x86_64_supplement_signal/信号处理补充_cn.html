本包是 Release python-offline-2026.11.06 的配套补充，单独发布在 Release python-offline-signal-v1-2026.11.06；不改各环境组的 requirements_lock_en.txt。

安装（在已有 03 环境上追加）

先按环境组目录装好 03_signal_audio_image_*，再在同一个 venv 中执行：

bash ./install_supplement_en.sh

脚本只会安装 requirements_supplement_en.txt 中的新增包，并从 packages_wheel/ 以及03 组（及 13 组）wheelhouse 解析依赖。

必须使用 runtimes/ 中对应的 CPython 3.10.22 / 3.12.16，不要装进 3.14。

实时滤波 vs 离线平滑

  • 实时 / 因果：filterpy.kalman.KalmanFilter.predict + update，或 pykalman.KalmanFilter.filter。时刻 t 的输出只依赖 z[0]..z[t]。
  • 离线平滑：pykalman.KalmanFilter.smooth（RTS）。时刻 t 的输出依赖 z[0]..z[N-1]，含未来观测。滞后更小、误差通常更低，不能接到必须在采样时刻给出估计的控制回路。

开发板

库中开发板侧是 Raspberry Pi OS Bookworm Python 3.11 的 GPIO 通讯包，不是 3.10/3.12。 本包不为 3.11 板子补信号库，也不把 x86-64 二进制放进板端目录。 仅当存在 aarch64 + 对应 CPython 3.10/3.12 的 wheel 时，才写入 embedded_boards/aarch64/。 armv7l 若无官方 wheel，源码与构建依赖放在 packages_sdist_unbuilt/，状态为 未构建、未验证。
